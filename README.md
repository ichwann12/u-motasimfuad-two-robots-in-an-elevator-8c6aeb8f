## Run

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only — no network, no wall clock) reads the entry
line from `entry.txt` and writes it to `output.txt` inside the directory from
`MAKEFUN_OUTPUT_DIR` (or `MAKEFUN_BOT_DIR`, default `output/`).
